# Python Keyword Only Arguments

This example demonstrates Python's keyword-only arguments feature. It defines a function where certain parameters can only be passed using their keyword, improving code readability and preventing common positional argument errors. The script shows correct function calls and intentionally triggers `TypeError` exceptions to illustrate what happens when keyword-only arguments are passed positionally or omitted.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
